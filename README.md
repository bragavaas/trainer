# Treino

PWA de registro de musculação. Offline, sem backend, dados em localStorage.

## Hospedar no GitHub Pages

1. Crie um repositório (ex: `trainer`) e suba estes 5 arquivos na raiz:
   `index.html`, `manifest.json`, `sw.js`, `icon.svg`, `README.md`
2. Settings → Pages → Source: "Deploy from a branch" → branch `main`, pasta `/ (root)`
3. Aguarde 1 a 2 min. A URL fica `https://bragavaas.github.io/trainer/`

## Instalar no iPhone

Abra a URL no Safari → botão Compartilhar → "Adicionar à Tela de Início".
Depois disso abre como app, sem barra do navegador, e funciona sem internet.

## Dados

Ficam só no aparelho. Use Config → "Backup JSON" de vez em quando.
Os CSVs exportados seguem o mesmo formato da planilha antiga.
